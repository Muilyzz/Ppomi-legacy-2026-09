# v0.2 Mac 셸 — 메인 앱에서 테스트 (example 아님)

소비자가 클릭하는 Mac 앱은 **이미 있는 `뽀미.app` / `Ppomi.app`** 이다. 새 `ppomi-*` 패키지를 만들지 않는다.

**패키지 example CLI로 스모크하지 않는다.** 해피 패스는 채팅 한 줄이다. **Home → KB** 버튼은 스모크일 뿐 누르지 않는다.

## Mac에서 열고 한 스텝

Finder에서 `scripts/open-mac-shell.command` 를 더블클릭한다. 터미널이 뜨고, 있는 앱을 연다. 없으면 `scripts/make-app.sh` 로 `dist/Ppomi.app` 을 만든 뒤 연다.

```sh
scripts/open-mac-shell.sh
scripts/open-mac-shell.sh --build          # 항상 다시 패키징
scripts/open-mac-shell.sh --dry-run        # 빌드/열기 없이 안내만
scripts/open-mac-shell.sh --self-check     # Linux에서도 통과하는 문자 검사
```

또는

```sh
cd Ppomi && swift run Ppomi
# 설치 번들
LOCAL_SIGN_ID="Apple Development: …" scripts/make-app.sh
open dist/Ppomi.app
```

권한: 채팅이 `path_cold_start` 등을 호출했는데 손쉬운 사용·화면 기록이 없으면 **시스템 허용 창 + 입력창 위 권한 허용 버튼**이 먼저 나온다. 버튼 → 작은 얼럿 → 시스템 허용. 이미 거절되어 다시 물을 수 없을 때만 설정 › 시작하기가 열리고, 거기서 경로를 안내한 뒤 다시 실행한다. 마이크는 통화할 때만 `requestAccess`. 이미 켜져 있으면 콜드스타트는 그대로 진행한다.

서명: 이 스크립트는 `SIGN_ID` / `NOTARY_PROFILE` 을 거부한다. TCC가 안 끊기게 쓰려면 `LOCAL_SIGN_ID="Apple Development: …"` 만. 스토어·공증은 하지 않는다.

이미 `/Applications/뽀미.app` 이 있으면 그걸 연다 (`--build` 가 아닐 때).

### 채팅 한 줄 (버튼 아님)

1. 뽀미를 연다. 기본 화면이 대화다.
2. (선택) 나(아바타) → Google 로그인. Clerk 웹 로그인(who)과 별개다. 이 Mac 세션이 where 다. 작업대가 열리거나 로그인이 끝나면 `DeviceRegistry.attach` 가 이 macos 기기를 로컬 플릿에 올린다.
3. 채팅에 `KB 사업자 계좌 읽어줘` 라고 보낸다. **Home → KB** 를 누르지 않는다.
4. 인앱 에이전트가 `path_cold_start(app: kb-enterprise)` 를 호출한다. 라이브 미러링에 `phone_key home` 후 `phone_open(kb-enterprise)`. Face ID·로그인에서 멈춘다.
5. 계좌번호·비밀번호는 읽거나 채팅·로그에 쓰지 않는다. 사람 차례는 Face ID / OTP / 비밀번호만.

같은 손을 외부 브레인에 붙일 때:

```sh
# 앱과 같은 손. packages/.../example 이 아니다.
# 클라이언트에 Ppomi --mcp 를 붙인 뒤 같은 한 줄 → path_cold_start(app: "kb-enterprise")
```

**Home → KB** 버튼·절차 탭은 같은 도구의 스모크다. 해피 패스 검증에 쓰지 않는다.

### 권한 UX 확인 (Mac)

1. 손쉬운 사용·화면 기록을 끈 뒤(또는 한 번도 허용하지 않은 빌드) 채팅에 `KB 사업자 계좌 읽어줘`.
2. 설정 창이 바로 열리지 않고, 시스템 허용 창 또는 입력창 위 **권한 허용**이 보여야 한다. 버튼을 누르면 작은 얼럿 → 시스템 허용.
3. 시스템에서 거절한 뒤 같은 말을 다시 보내면 그때만 설정 › 시작하기가 열리고, 손쉬운 사용·화면 기록 경로와 다시 실행이 보여야 한다.
4. 두 권한을 켜고(화면 기록은 다시 실행) 같은 말을 보내면 Home 후 KB가 이전과 같이 진행된다.

## web / Clerk (`ppomi-web`)

`hub/` 는 공개 카탈로그다. 본인증(who)은 `web/` 만. Mac 앱 세션은 여전히 `ppomi://auth` Google(Supabase).

```sh
cd web
cp -n .env.example .env.local   # 실제 pk_/sk_ 를 사람이 붙인다
npm install && npm run dev      # http://127.0.0.1:3000
```

키 있으면 Google 로그인 → `/account`. 키 없으면 설정 안내만. 설계는 [clerk-migration.md](clerk-migration.md).
