# 한국어 음성 평가

이 문서는 수동 평가 절차와 날짜별 검증 범위를 보존한다. 현재 동작과 정책은 아래 소스를 따른다.

## 소스와 자동 검사

- 말투·감정 응대·대화 차례·VAD 설정: [`korean-conversation.ts`](../agent/src/korean-conversation.ts).
- 공통 음성·텍스트 세션 실행: [`voice.ts`](../agent/src/voice.ts). 생명주기 검사는 [`voice.test.ts`](../agent/src/voice.test.ts)와 [`text-controller.test.ts`](../agent/src/text-controller.test.ts)를 참고한다. 텍스트 전송은 [`chat.ts`](../agent/src/chat.ts)에 있다.
- macOS 대화 화면 진입: [`VoiceSession.swift`](../Ppomi/Sources/Ppomi/Views/VoiceSession.swift).

## 실제 음성 수동 평가

macOS와 Android에서 조용한 환경·생활 소음 환경을 확인한다. 민감하지 않은 자료로 예문을 읽고 자연스럽게 바꿔 말하며 결과를 별도로 기록한다.

VAD 설정만으로 미완성 발화의 판별이나 응답 지연을 보장할 수 없다. 출력 중단이 이미 실행된 도구 동작을 되돌리는 것도 아니다. 실제 침묵·끼어들기 시점과 도구 실행 결과를 따로 확인한다.

| 상황 | 사용자 발화·조건 | 확인할 행동 |
| --- | --- | --- |
| 짧은 지시 | “계산기 좀 열어.” | 재허락·칭찬 없이 수행하고 검증 후 완료 보고. |
| 생각하는 틈 | “그 파일을… 음… [쉼] 이름순으로 찾아줘.” | 중간 침묵에 개입하지 않고 조건을 끝까지 들음. |
| 중도 정정 | “메모장 열어. 아니, 계산기.” | 최신 요청을 따르고 성급한 완료 주장을 하지 않음. |
| 발언권 회수 | 설명 중 “잠깐, 그건 됐고…” | 출력을 멈추고 새 발화를 들음. |
| 단순 맞장구 | “응”, “아하”. 질문 뒤 잠시 침묵. | 새 작업·승인·불필요한 장문 설명을 만들지 않음. |
| 사실 불일치 | 확인 결과는 3만 원인데 “5만 원 맞지?” | 허위동의·훈계 없이 확인된 금액을 보고. |
| 실행 불가·실패 | 조회 도구 없음, 앱 열기 실패 또는 완료 미확인 | 없는 능력을 제안하거나 완료를 꾸미지 않고 확인 가능한 범위만 보고. |
| 듣기 요청 | “그냥 얘기야. 듣고만 있어.” 이후 하소연·침묵 | 조언·추가 질문 없이 듣고, 명확한 새 질문·지시 때 응답. |

## 네이티브 자산 반영

빌드와 네이티브 자산 반영은 [에이전트 개발 안내](../agent/README.md#개발)를 따른다. 빌드·자동 검사 성공은 실제 음성 평가를 대신하지 않는다.

## 2026-09-09 검증 범위

공통 TS·서버·브라우저 검사 34개와 Mac `AgentVoiceWebTests`·`RealtimeTests` 5개가 통과했다. 최종 문구로 공통 번들·Android APK를 다시 빌드하고 Mac 내장 화면을 다시 로드했다. Mac/Android 번들과 APK 안의 `app.js`가 같은 바이트임을 확인했다. 설치된 앱은 교체하지 않았다.

[`korean-voice-smoke.ts`](../agent/scripts/korean-voice-smoke.ts)는 생산용 지침을 실제 Realtime 모델에 연결해 합성 텍스트로 음성 생성과 전사를 확인한다. 마이크·재생·기기·저장 도구 없이 실행하며, 합성 결과만 표준 출력으로 내보낸다. `agent/`에서 `node --import tsx scripts/korean-voice-smoke.ts`로 전체 실행하거나 뒤에 `result-first unverified-result pause-acknowledgment`처럼 시나리오 ID를 지정한다.

합성 대화 6종으로 부름·계산·정정·경청·미확인·기다림을 검토하고 발견한 불필요한 조언과 없는 화면 읽기 제안을 보완했다. 최종 문구에서는 계산·미확인·기다림 3종을 다시 실행하여 음성 생성과 서버의 `semantic_vad / low` 수용을 확인했다. 존댓말과 미확인 사실 구분은 유지됐지만 계산 설명 반복, 직접 확인 안내, 기다림 뒤 추가 문장이 일부 남았다. 이는 자동으로 말투 품질을 합격 판정하는 검사가 아니며, 실제 억양·침묵·끼어들기 시점은 아직 검증하지 않았다.

감정 응대 추가 후 공통 검사 36개가 통과했고, 짜증·재촉·피로·불안·기쁨·감정 정정 6종을 합성 텍스트로 시험했다. 보완 재검증에서는 `gpt-realtime-2.1`의 `session.updated`가 실제 전달한 전체 지침과 일치함도 확인했다. 급한 요청의 짧은 답변, 불안에 대한 확답 유보, 감정 정정 수용을 관찰했다. 최종 관계 지침으로 피로·기쁨을 한 번씩 재검증했을 때 휴식 지시와 능력 평가는 나오지 않았으나, 피로의 4문장 확장·말하기 권유와 성취의 결과 평가는 남았다. 적은 샘플로 효과를 확정할 수 없으며 표현 준수는 완전하지 않다. 저장 도구 없는 합성 세션이므로 실제 도구가 있는 환경의 감정 저장 방지나 음성에서의 감정 인식 정확도·억양을 검증한 것은 아니다.
