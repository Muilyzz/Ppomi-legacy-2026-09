# 에이전트 대화창과 작업 화면

뽀미의 왼쪽 영역에서 ‘대화 / 기록’을 전환한다. 대화에서는 설치된 ChatGPT 또는 Codex의 실제 macOS 창을 배치하고, 오른쪽에는 선택한 iPhone 미러링 또는 Parallels 창을 둔다. 기존 장부·절차·몸과 생활은 기록에서 그대로 사용한다. 승인 버튼은 두 창의 바깥, 작업대 하단에 유지한다.

이 기능은 외부 창의 크기·위치·순서를 함께 관리한다. 대화 내용 복제, 웹뷰 로그인, 채팅 전송, MCP 등록이나 연결 성공 판정을 하지 않는다. MCP 서버 설정은 해당 에이전트의 설정을 따르며, 창이 보인다는 사실은 도구가 연결됐다는 뜻이 아니다.

외부 앱은 설치 번들의 식별자와 실행 파일로 확인한다. 앱 이름만으로 구분하지 않으며 여러 대화창이 있을 때는 확인된 한 창을 계속 사용한다. 연결 후 일반 클릭·스크롤·타이머 조회는 대화창을 활성화하거나 원래 위치로 계속 끌어오지 않는다. 사용자가 다시 배치하거나 창 모드·디스플레이·작업 화면의 실제 배치가 바뀔 때만 크기를 다시 맞춘다.

실제 창의 최소 크기가 대화 영역보다 크면 승인을 가리지 않도록 도킹을 중단하고 안내한다. iPhone·Windows·대화·장부 네 개를 동시에 축소 표시하지 않는다. 기록으로 전환하면 관리하던 대화창 하나를 최소화하고, 대화로 돌아오면 다시 표시한다. 뽀미 작업창을 닫거나 앱을 정상 종료하면 대화창의 원래 크기·위치·최소화 상태를 복원한다.

키오스크에서는 실제 대화창과 작업 화면을 제외한 영역을 덮는다. 대화창 위에는 같은 전환 도구막대, 아래에는 같은 승인 컨트롤을 배치한다. 기존 아무 키로 나가기 버튼 표시·두 번째 Escape로 종료 동작을 유지한다.

기하·창 선택·입력 포커스는 화면을 조작하지 않는 테스트로 검증한다. 실제 앱 최소 크기, 접근성 권한, Stage Manager/Spaces의 창 순서와 키오스크 복귀는 잠금 해제된 Mac에서 별도 확인해야 한다.
