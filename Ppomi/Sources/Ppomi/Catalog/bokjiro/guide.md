# 복지로 (보건복지부 · Windows 우선)
- 2026-09-10 홈 HTML이 TouchEn nxKey·XecureKeyPad·nProtect(nppfs)·AnyID 스크립트를 싣고, 기초연금 안내에 "공동인증서(구. 공인인증서) 필요"가 적혀 있다. Mac Chrome은 메뉴·안내 읽기 같은 탐색만 하고, 로그인·신청은 처음부터 `windows_open(app: bokjiro)`으로 Parallels에서 연다.
- `windows_open`은 브라우저 새 탭이다. 같은 탭 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 닫기는 `windows_key ctrl+w`. 좌표·포커스는 `windows_screen`으로 매번 다시 본다.
- 휠은 포인터가 창 안에 있어야 먹는다(도구가 들여보낸다). 안 움직이면 빈 곳을 `windows_click` 뒤 다시, 또는 `windows_key pagedown`. 공지 상자 위에서는 그 상자만 스크롤된다.
- 위젯 보드(날씨·뉴스)가 덮으면 `windows_key win` 한 번 뒤 `windows_key escape`. 자바스크립트 알림은 escape.
- 페이지가 SPA(cleopatra)라 첫 그림까지 수 초 걸린다. 흰 화면이면 5초 기다렸다가 다시 `windows_screen`.
