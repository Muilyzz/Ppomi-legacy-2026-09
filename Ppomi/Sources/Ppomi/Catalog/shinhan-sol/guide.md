# 신한 슈퍼SOL

## 목적과 범위

iPhone의 신한 슈퍼SOL(옛 신한 SOL뱅크를 합친 앱)에서 입출금 잔액과 대출 잔액을 읽는다. 읽기만 한다. 이체·이자납부·상품 가입은 하지 않는다.

## 화면 (2026-09-11 실제 확인)

- Spotlight에 '신한'을 치면 맨 위에 '신한 슈퍼SOL'과 '신한카드'가 나란히 나온다. 슈퍼SOL 아이콘을 누른다.
- 처음 열면 iOS가 "'신한 슈퍼SOL'이(가) 'MacBook Pro'에서 붙여넣으려고 함"을 묻는다. '붙여넣기 허용 안 함'을 누른다(수집기 팝업 규칙에 있음).
- 홈: '계좌' 카드에 입출금 계좌 두 줄(이름 줄 → '금액원 이체' 줄). 대출은 홈에 없다.
- 홈의 '계좌' 제목을 누르면 전체계좌: '입출금 N / 합계', 계좌마다 이름 줄 → '신한 계좌번호' 줄 → '금액원 이체' 줄; 아래 '대출 N / 합계', 대출마다 이름 줄('<기시>일반자금대출(분할상환)' 같은 꼴) → 계좌번호 줄 → '금액원 이자납부' 줄.
- 합계 줄('입출금2', '대출2 〉')은 계좌가 아니다. 계좌 정규식은 '예금$|대출\('로 이름 줄만 잡는다.

## 장부 규칙

- 대출 잔액은 갚을 돈이다. `collection.debt`("대출")에 맞는 이름의 잔액은 음수로 저장되고, 재무 상태에서는 부채 › 차입으로 간다.
- '사업자'가 이름에 있는 계좌와 '<기시>'(기업시설자금)·'<기운>'(기업운전자금) 대출은 사업자 구분이다(Rules.businessLabel). 나머지는 가계부.
- OCR이 '보통예금'을 '보동예금'으로 읽는 일이 있다. 라벨이 둘로 갈리면 장부에서 같은 계좌로 합쳐야 한다(아직 규칙 없음).
