## Windows (Parallels)
- Mac에서 보안프로그램 설치 요구·공동인증서 창이 안 열려 실제 단계가 막힌 경우에만. `windows_open(app: "work24")`로 Parallels 브라우저 새 탭에 연다. 같은 탭 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 다 쓴 탭은 `windows_key ctrl+w`.
- 휠은 포인터가 창 안에 들어온 뒤에만 먹는다(도구가 들여보낸다). 안 움직이면 빈 곳 windows_click 뒤 다시, 또는 windows_key pagedown. 위젯 보드가 덮으면 windows_key win → windows_key escape. JS 알림은 escape.
- 공동인증서는 joint-certificate 플레이북대로 Windows에 옮겨진 것을 쓴다. 인증서 암호는 당사자.
- 결제는 없다. 결제 화면이 나오면 Mac Chrome은 당사자가 직접, Windows는 confirm_payment 1회 → windows_click 1회.
