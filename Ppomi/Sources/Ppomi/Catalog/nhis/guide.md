# 국민건강보험 (Windows · Parallels)
- 보건복지부 산하 국민건강보험공단. 로그인이 공동·금융인증서 또는 간편인증이고 PC 방화벽·키보드보안 프로그램(exe) 설치 안내가 있는 사이트라 `windows_open(app: nhis)`으로 Parallels에서 연다. Mac Chrome 탐색은 공개 페이지 확인용이며 로그인 이후 단계는 Windows에서 한다.
- `windows_open`은 브라우저 새 탭으로 연다. 같은 탭 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 다 쓴 탭은 `windows_key ctrl+w`. 화면은 매번 `windows_screen`으로 새로 읽고 좌표·포커스를 다시 확인한다(OCR·좌표 기반, DOM 없음).
- 휠은 포인터가 창 안에 들어온 뒤에만 먹는다(도구가 들여보낸다). 안 움직이면 페이지 빈 곳을 `windows_click` 뒤 다시, 또는 `windows_key pagedown`. 위젯 보드(날씨·뉴스)가 덮으면 `windows_key win` 한 번 뒤 `windows_key escape`. 자바스크립트 알림은 `escape`.

## 관찰 (2026-09-10, 공개 페이지 WebFetch)
- 홈 https://www.nhis.or.kr/ → https://www.nhis.or.kr/nhis/index.do. 상단 메뉴 "민원서비스 / 건강모아 / 정책·제도 / 정보공개 / 국민소통·참여 / 공단소개". 로그인 문구 "로그인을 해주세요" → `/nhis/etc/personalLoginPage.do`.
- 홈 바로가기 링크: 보험료 납부확인서 `/nhis/minwon/jpAea00101.do`, 보험료 납부 `/nhis/minwon/jpAba00100.do`, 자격득실 확인서 `/nhis/minwon/jpAea00401.do`, 검진대상 조회 `/nhis/healthin/retrieveHealthinCheckUpTargetPerson.do`, 건강검진 결과조회 `/nhis/healthin/retrieveHealthinCheckUpTargetResultPerson.do`. 위 다섯 주소는 비로그인 상태에서 모두 로그인 페이지로 이동했다.
- 로그인 페이지(https://www.nhis.or.kr/nhis/etc/personalLoginPage.do): "개인 회원 / 사업장 회원", 버튼 "간편 인증"(네이버·카카오·PASS·토스 등 민간 인증서), "공동·금융 인증서", "인증서관리 / 인증서등록", "회원가입", "아이디/비밀번호찾기". 안내 "PC 방화벽 보안프로그램 선택 설치", "키보드보안프로그램 선택 설치".
- 자격득실확인서 이용가이드(https://www.nhis.or.kr/static/html/guide/sub2_010103.html): 경로 "홈 > 민원신청 따라하기 > 개인민원 > 자격득실확인서 발급", 순서 서비스 선택 → 자격 득실 내역 확인 → 증명서 발급. 출력 "프린트 발급"(새창 미리보기 → 프린터 선택), "팩스 전송"(팩스번호 입력 → [팩스보내기]). 미리보기가 안 뜨면 "수동 설치 후 재시도" 안내. 서비스 안내(minwonServiceBoard articleNo=10945783): 전자증명서는 건강보험25시·정부24·네이버·카카오 전자문서지갑.
- 미검증: 로그인 뒤 실제 상단 메뉴명("민원여기요 / 개인민원 / 증명서 발급 및 확인"은 외부 검색 요약), 보험료 조회 화면의 열 이름·납부 수단 목록·납부 버튼 문구, 건강모아 "나의 건강 > 검진대상 조회" 메뉴명, "검진결과 한번에보기" 버튼, 보안프로그램 실제 설치 여부, 간편인증 완료 흐름.

## 절차
- 진입: 홈에서 상단 메뉴를 읽어 "민원서비스"(또는 "민원여기요") → "개인민원" 아래 항목을 찾는다. 글자가 OCR로 안 잡히면 위 직접 주소를 `ctrl+l`로 입력한다. 어느 쪽이든 로그인 페이지로 가면 정상.
- 로그인: 사용자가 정한 방식 버튼(간편 인증 | 공동·금융 인증서)까지 클릭해 준비하고 멈춘다. 간편인증은 폰 앱 승인, 인증서는 암호 입력이 당사자 차례. 완료 응답 뒤 새 화면을 읽어 로그인 상태를 확인하고 원래 항목으로 돌아간다. 보안프로그램 설치 알림은 선택 설치이므로 재설치를 반복하지 않는다.
- 보험료: 조회 화면에서 기간·건강보험료·장기요양보험료·합계를 읽어 보고한다. 납부는 사용자가 요청한 경우에만 ✋ `confirm_payment`(금액·수단·대상 한 줄) → `windows_click` 1회 → 결제 인증은 당사자. 결과 화면을 읽고 `record_spend`.
- 자격득실확인서: 득실 내역을 읽고 사용자가 정한 방식(프린트 · 팩스 · 전자증명서) 버튼까지 간다. 프린터 대화상자·팩스번호 입력·전자문서지갑 수신은 당사자가 확인한다. 발급 완료 문구를 확인한 뒤에만 완료 보고.
- 건강검진: 검진대상 조회에서 올해 대상 검진 종류를, 결과조회에서 연도별 판정·주요 수치를 읽는다. 사용자가 저장을 요청하면 `record_health`. 수치는 화면에서 읽은 값만, 추정하지 않는다.
- 개인정보(이름·주민번호·주소·금액 원문)는 플레이북·발자국에 적지 않는다. 사람 차례에는 현재 단계·필요한 행동·완료 판별 화면·돌아갈 작업을 한 번만 안내한다.
- 검증 상태: 공개 페이지·로그인 페이지·이용가이드만 확인. Windows 실기(로그인·조회·납부·발급)는 아직 검증하지 않았다.
