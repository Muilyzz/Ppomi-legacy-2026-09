# KB스타기업뱅킹

**메인 앱에서 테스트한다.** 작업대 제어 머리띠 또는 대화 창의 **Home → KB** (MCP `path_cold_start`). `packages/*/example` 이 아니다. Home 후 앱을 열고 Face ID·로그인에서 멈춘다.

## 목적과 범위

iPhone에서 해당 사업자로 로그인해 KB ID 조회에 필요한 통장 정보를 확인한다. 여기의 **KB국민인증서(기업)** 준비는 모바일 로그인 경로이며, Parallels Windows의 **공동인증서 발급·재발급**과 별도 단계다. 사용자가 모바일 인증서 준비를 선택한 경우에만 그 경로를 이어가고, 계좌 조회 목적을 새 인증서 발급의 포괄적 허가로 확대하지 않는다.

## 연결과 기존 로그인

- 사용자가 폰을 가져왔다거나 잠갔다고 알리면 iPhone 미러링의 현재 화면·AX 상태부터 확인한다. ‘iPhone 사용 중’ 안내가 과거 상태로 남아 있고 활성 ‘연결’ 버튼이 있을 수 있다. 정확한 미러링 재연결 버튼을 한 번 누르고 실제 홈·앱전환기 표시 등 연결 결과를 확인한다. 실제 사용 중 안내가 계속될 때만 잠금이 필요함을 알린다. 같은 안내만 보고 잠금을 반복 요청하지 않는다.
- KB스타기업뱅킹은 일반 KB스타뱅킹과 다른 앱이다. 현재 설치 앱 이름을 확인해 연다. 로그인 완료 상태면 다시 인증을 요구하지 않는다. 앱의 ‘KB국민인증서’, ‘KB국민인증서(기업)’, ‘공동인증서’, ‘금융인증서’, ‘간편회원 로그인’을 구분한다. 등록된 공동인증서가 없다는 안내에서 새 발급·가져오기를 임의 선택하지 않는다.

## KB국민인증서(기업) 정보 준비

2026-09-09 실제 빈 화면에서 ‘KB국민인증서(기업)’·‘인증서 정보를 입력해주세요.’ 아래 사업자등록번호 3-2-5 세 칸, 휴대폰번호 010 선택과 뒤 번호 칸, SMS 발송 안내, 정보 저장하기, 인증서 발급하기 링크, 다음 버튼을 확인했다. 정보 입력 화면·링크 표시를 인증서 발급 완료로 기록하지 않는다.

1. 이번 사용자의 `profile_status`로 사업자번호·휴대폰번호 등록 여부를 확인한다. 이미 등록된 값은 재질문하지 않는다.
2. `profile_fill(form: kb_enterprise_certificate_info, field: business_registration_number, segment: 1|2|3)`와 `field: phone`으로 각 칸을 준비한다. 좌표는 현재 빈 폼을 기준으로 하고 각 호출이 로컬에서 양식·빈칸·포커스를 재검증하게 한다. 번호 원문은 에이전트에 반환하지 않으며 일반 입력 도구로 우회하지 않는다.
3. 발급 절차의 ‘휴대폰 본인인증’ 이름 화면은 `profile_fill(form: kb_enterprise_phone_identity, field: name)`으로 한글 이름 칸만 채운다. 이어지는 주민번호·통신사·인증번호는 당사자가 입력한다.
4. 등록된 010 휴대폰은 뒤 8자리만 입력한다. 고객명·계좌번호·비밀번호·인증번호를 이 어댑터에 넘기지 않는다. 값 일치가 불확실하면 입력을 반복하지 않는다. 입력 후 일반 화면 수집으로 원문을 기록하지 않는다.
4. 현재 버튼 효과와 기존 허용 범위를 확인해 인증 요청을 준비한다. SMS·비밀번호·생체 인증·새 자격증명은 준비된 공식 화면에서 당사자가 직접 처리한다. 이후 결과 화면으로 인증서 준비·로그인 성공을 각각 확인한다.

## 계좌 확인과 복귀

로그인한 사업자와 필요한 출금계좌를 확인한다. 통장 고객명은 이름과 상호를 임의 조합하지 않고 은행에 등록된 전체 표기를 사용한다. 여러 계좌가 있거나 일부 마스킹되어 있으면 추정하지 않는다. 현재 범용 `phone_screen`은 캡처·OCR 장부를 남기므로 계좌 원문 추출·저장의 대체재로 쓰지 않는다. 전용 비공개 추출이 지원되지 않으면 뽀미 Mac의 KB 은행정보 카드에 미등록 항목만 직접 입력한다.

계좌 정보가 준비되면 `joint-certificate` 플레이북의 Parallels KB 개인사업자 ID 조회로 돌아간다. 모바일 인증서·로그인·계좌 확인·Windows 공동인증서 발급·USB 복사는 각각 결과를 확인한다.
