### 2. 사업자 입력을 받아도 명세가 일반회원 경로로 안내

`manifest.json:15`에는 가입 유형 입력이 있지만 `:20`의 `prepare-form`은 일반회원 가입하기로 고정되어 있다. 일반 본인인증과 사업자 공동인증의 요구사항도 구분하지 않는다. 상세 guide의 사업자 절차와 충돌하므로 현재 유형에 따라 단계·입력·인증 방식을 선택하도록 수정해야 한다.

### 3. Mac 시작 절차와 Windows 전용 입력기 사이의 연결이 불명확

사업자 guide `:78`은 `profile_fill(form: eais_business)`를 사용하도록 안내하지만 이 도구는 Windows 양식 전용이다(`Tools.swift:341, 644–646`). Mac Chrome에 사업자 폼이 보이는 것만으로 이 입력기를 사용할 수 없다. 해당 단계의 지원 환경과 Mac에서 진행 가능한 범위를 명시해야 한다.

### 4. 같은 버전에 서로 다른 절차와 오래된 상태 기록이 섞임

사업자 안내가 없는 설치본과 안내가 추가된 원본 모두 `0.1.1`이다. 절차 변경 시 버전을 올리는 규칙(`docs/playbook-format.md:89`)에 맞춰 갱신해야 한다. guide `:21`의 사업자 다음 화면 미확인 문구와 `:76`의 후속 확인 기록도 확인 시점·환경을 구분해야 한다. `docs/eais-macos-browser.md:142,151`의 PASS 대기 상태 역시 후속 가입 필요 상태와 구분이 필요하다.

MCP의 현재 버전 재생 수치는 저장 단계·재생 단계·성공·실패 모두 0이었다. 웹 단계 명세나 이번 수동 브라우저 탐색을 자동 콤보 재생 성공으로 합산하지 않았다.
