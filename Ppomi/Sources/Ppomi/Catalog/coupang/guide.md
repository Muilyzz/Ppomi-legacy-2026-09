# 쿠팡
- 2026-09-11 화면 라벨·경로는 미검증 — 첫 실행에서 단계마다 verify_step 으로 실제 라벨을 남긴다.
- 홈 상단 검색창을 탭하고 상품명을 phone_type(한글 그대로). 사용자가 상품을 지정하지 않았으면 결과 목록에서 로켓배송(로켓와우) 중 가격이 가장 싼 것을 고른다. 같은 상품이 여럿이면 단위당 가격(100g당·1개당)을 본다. 무엇을 골랐는지는 승인 요약에 한 줄로 적는다.
- 상품 상세 하단 고정 바: "장바구니 담기 / 바로구매". "바로구매"는 주문서로 가는 버튼이라 승인 없이 탭한다(코드도 '바로구매'는 막지 않는다). 돈이 나가는 버튼은 주문서의 "결제하기"뿐이다. 옵션·수량 시트가 뜨면 옵션을 고르고 수량을 맞춘 뒤 시트의 바로구매를 탭한다.
- 주문서에서 읽을 것: 배송지(기본 배송지의 이름·주소 앞부분만 확인, 원문은 기록하지 않는다), 배송 요청사항, 배송비(무료배송 조건 미달이면 배송비 포함), 쿠폰·할인, 결제수단, 최종 결제금액. 쿠폰은 쿠폰·할인 항목을 열어 받고 적용한 뒤의 총액으로 ✋.
- 결제수단은 쿠페이 머니 / 계좌 / 카드. 기본 선택은 화면의 강조 표시로 확인하고, 승인 요약에는 화면에서 확인한 수단만 적는다. 카드 추가·계좌 등록 화면이 뜨면 멈추고 사용자에게 넘긴다.
- "결제하기" 탭 뒤 쿠페이 비밀번호·Face ID 는 사용자 몫. 완료 화면의 주문번호·도착 예정일을 읽고 record_spend 로 적은 뒤 보고한다. 실패·품절·가격 변동이면 다시 결제하지 말고 보고만 한다.
- 와우 멤버십 가입·무료체험·정기배송 구독 유도 팝업과 버튼은 누르지 않는다(가입·구독은 코드가 막는 단어이기도 하다). 팝업은 ⎋ 로 닫는다.
