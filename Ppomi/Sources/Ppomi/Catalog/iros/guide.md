# 인터넷등기소 (Mac Chrome 우선 · 필요한 단계만 Windows)
- `browser_open`으로 https://www.iros.go.kr/ 를 Mac Chrome에서 열고 연결된 브라우저 도구로 현재 DOM을 읽는다. PC 웹이라는 이유만으로 Windows를 선택하지 않는다. 홈페이지와 일반 탐색은 2026-09-08 Mac에서 확인했다. Mac에서 해당 업무가 막힌 원인을 확인하고 공식 Mac 경로로 해결되지 않을 때만 Parallels의 `windows_*` 도구를 사용한다.
- 2026-09-08 고객센터 → 프로그램 설치 화면은 현재 OS를 `mac universal`로 표시하고 AnySign4PC와 TouchEn nxKey의 Mac 다운로드를 제공했다. 설치파일이 있다는 사실만으로 인증·열람·발급·출력 성공을 단정하지 않는다. 필요한 제품과 OS를 확인하고 이미 허용된 공식 안내·다운로드·설치 준비를 이어간다. 관리자 인증과 새 민감 접근 권한은 그 지점에서만 사람에게 넘긴다.
- Windows를 사용하는 경우 `windows_open`은 브라우저 새 탭으로 연다. 같은 탭의 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 다 쓴 탭은 `windows_key ctrl+w`다. 화면 좌표와 포커스는 매번 새로 확인한다.
- 2026-09-07 홈(https://www.iros.go.kr/): 상단 메뉴 "열람·발급 / 신청 / 등기지원 서비스 / 나의 등기정보 / 고객센터", 오른쪽 위 "로그인 ∨ / KOR". 가운데 "부동산 | 법인" 탭과 "부동산 등기사항증명서를 열람·발급하려면 주소를 입력하세요" 검색창, 아래 카드 "부동산 열람·발급 / 법인 열람·발급 / 부동산등기 신청 / 법인등기 신청 / 전자신청 서명 / 전자납부 / 서비스 더보기".
- 홈에는 NEWS 띠(위)와 "사용자지원센터 1544-0770" 카드(오른쪽, X로 닫기), 챗봇·맨 위로 버튼(오른쪽 아래)이 떠 있다. 카드가 글자를 가리면 X를 클릭한다.
- 2026-09-08 열람·발급 → 부동산 메뉴에서 `소유현황 열람`을 확인했다. 이름이나 주민번호만으로 공개 조회 가능한 목록이라는 뜻은 아니며, 해당 서비스의 본인인증·대상·수수료를 현재 화면에서 확인한다. 사용자가 소재지 목록을 이미 제공했다면 그 주소로 검색한다. 이전 열람 내역이 필요하면 현재 메뉴의 신청결과 또는 열람·발급 내역 경로를 확인한다.
- 열람·발급 수수료(열람 700원, 발급 1,000원 — 화면 금액으로 확인)는 최종 금액·결제수단·대상을 확인해 안내한다. Mac Chrome의 최종 결제 버튼은 당사자가 직접 누르고 결제 인증을 마친다. `browser_open`은 탐색만 제공하고 외부 브라우저 클릭에는 뽀미의 승인 코드 경계가 없으므로, 승인을 받아도 브라우저 도구로 최종 결제를 자동 클릭하지 않는다. Windows를 이미 사용 중이면 ✋ confirm_payment 승인 1회에 windows_click으로 결제 버튼을 한 번 누르는 기존 코드 경계를 사용하고 결제 인증은 당사자가 마친다. 로그인 진입과 일반 탐색·결제 전 준비는 계속한다.
- 2026-09-07 로그인 페이지(https://www.iros.go.kr/websquare/callWebsquare.do?w2xPath=06010100): 탭 "일반사용자 / 전자신청사용자", 왼쪽 "아이디 로그인"(아이디·비밀번호·가상 키패드), 가운데 "인증서 로그인"(인증서성명·주민등록번호)이 관찰됐다. 현재 화면에서 해당 방법을 준비한 뒤 자격 증명·본인인증 단계만 당사자에게 넘긴다. 당시 "열람/발급 서비스는 회원가입 없이 비회원 서비스로 이용할 수 있습니다." 안내가 있었다. 현재 목적에도 비회원 경로가 가능한지 확인하고, 불필요한 가입을 만들지 않는다.
- 2026-09-07 로그인 진입에서 보안프로그램 설치 필요 알림 뒤 TouchEn nx 설치 페이지(…/solution/raonnx/install/install_nxkey.html)로 이동했다. 이 문구만으로 재설치를 반복하지 말고 OS·공식 설치 상태·브라우저의 로컬 프로그램 접근 권한을 확인한다. 브라우저의 "이 장치에서 다른 앱 및 서비스에 액세스"는 새 접근 권한이므로 현재 대상과 효과를 설명하고 승인받는다.
- Mac에서는 연결된 브라우저 도구로 스크롤하고 새 화면을 확인한다. Windows에서 휠은 포인터가 창 안으로 들어온 뒤에만 먹는다(도구가 알아서 들여보낸다). 그래도 안 움직이면 페이지의 빈 곳을 windows_click 한 뒤 다시, 또는 windows_key pagedown. 공지·뉴스 상자 위에서는 그 상자만 스크롤된다.
- Windows 위젯 보드(날씨·뉴스 판)가 갑자기 덮으면 windows_key win 한 번 뒤 windows_key escape 로 닫힌다. 자바스크립트 알림(확인 하나)은 escape 로 닫힌다.
- 등기사항증명서 화면은 표제부 → 갑구(소유권) → 을구(저당권 등) 순서다. Mac에서는 연결된 브라우저 도구로 현재 문서를 읽고, Windows를 이미 사용 중이면 windows_screen으로 읽고 windows_scroll로 내려간다. 확인한 소유자·지분·근저당 채권최고액·설정일을 정리해 보고한다. 개인정보(이름·주민번호)는 플레이북·발자국에 적지 않는다.

## 가족별 가입·로그인과 재개

- 공통 플레이북의 계정 절차를 따른다. 이번 당사자의 계정만 사용하고 가족의 이전 세션·인증·승인을 물려받지 않는다. 이미 명확한 계정·목적·접근 방식은 다시 질문하지 않는다.
- 가입이 실제로 필요하면 현재 화면의 가입 진입점을 열고 필수 입력·약관·인증 방법까지 준비한다. 가입 폼의 정확한 단계는 아직 실기 검증하지 않았으므로 현재 화면에서 확인한 요소만 조작한다. 사용자가 제공했고 인터넷등기소에 사용하도록 허용한 이름·연락처·주소 등 일반 폼 정보는 진행 중 채우며, 필요한 정보가 없을 때만 질문한다. 실제 입력값은 공개 패키지나 발자국에 적지 않는다.
- 자격 증명·비밀번호 생성과 입력·인증서 암호·인증에 쓰이는 주민번호·OTP·생체인증·CAPTCHA는 당사자가 직접 처리한다. 새 동의·민감 권한·최종 약관 동의·가입 확정도 현재 대상과 효과를 확인한 뒤 당사자가 직접 처리한다. 선택 마케팅은 자동 동의하지 않는다. 일반 폼 정보가 개인정보라는 이유만으로 작성 준비 전체를 당사자에게 넘기지 않는다.
- 사람 차례에는 현재 단계, 필요한 행동, 완료를 판별할 화면, 돌아갈 작업을 한 번 안내한다. 완료 응답 뒤 새 화면에서 로그인 상태를 확인하고 검색·소유현황·열람 작업을 이어간다. 가입/로그인 완료와 등기 열람/발급 완료를 구분한다.
- 검증 상태: Mac의 홈페이지·메뉴·공식 Mac 설치 항목 확인, Windows의 기본 입력·탭 전환 확인. 회원가입 완료·로그인 성공·소유현황 조회·수수료 결제·문서 발급의 전체 경로는 아직 검증하지 않았다.

## 2026-09-11 부동산 열람 경로 (Mac Chromium, 브라우저 패널)

- 홈 검색창은 WebSquare 입력(id `mf_wfm_potal_main_sch_realCorp___input`). 도로명주소를 넣고 Enter만 치면 '부동산 등기사항증명서 열람·발급 신청' 화면으로 간다(검색 버튼 없음). 탭: 간편검색 / 소재지번검색 / 도로명주소검색 / 고유번호검색. 도로명주소가 병기되지 않은 등기는 지번으로.
- 결과표 열: 선택 · 번호 · 부동산고유번호 · 부동산구분 · 부동산표시 · 지도보기 · 등기상태. '선택' 체크 → 표 아래 '다음'(id `mf_wfm_potal_main_wfm_content_btn_next`). 옆에 '결제대상목록'·'장바구니목록'. 다음 화면 '부동산 소재지번 선택'(소유자 열은 참고용 `*`)에서 다시 선택 → 다음.
- '용도 및 추가사항 선택': 용도 = 열람 / 발급(출력) / 전자발급전송(정부24) / 전자발급전송(전자소송). 추가사항 = 공동담보/전세목록, 매매목록. 등기기록유형 = 말소사항포함 / 현재유효사항 / 현재소유현황 / 특정인 지분 / 지분취득이력. 취득가 확인용은 열람 + 매매목록 + 말소사항포함(여러 호를 한 번에 산 경우 거래가액이 매매목록에 실린다). 열람은 1시간 내 재열람·PDF 출력 가능.
- 여기서 '다음' → `/solution/raonnx/install/install_nxkey.html`(TouchEn nxKey 설치, 접속PC정보 MACOSX/Chrome). 이 벽은 로그인·비회원 입력 전에 온다. 설치는 사람의 결정(관리자 인증)이고, 그 뒤 비회원 열람의 이름·주민번호·캡차(2026-09-01 적용 공지)·결제 700원은 모두 당사자 차례다. 에이전트는 설치 페이지에서 멈추고 현재 단계·필요한 행동·완료 판별 화면을 한 번 안내한다.
- 열람 결과는 PDF로 저장해 `registry_read`(path, password?)로 읽는다: 소재지, 갑구 소유자(첫 글자만)·지분·거래가액·접수일·원인, 을구 근저당(순위·채권최고액·근저당권자·설정일·말소 여부). 주민번호는 읽지 않는다. 취득가 = 거래가액 + 취득세(위택스 납부내역 과세표준) + 중개수수료.
