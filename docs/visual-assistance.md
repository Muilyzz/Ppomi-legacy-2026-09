# VLM 화면 보조

`phone_screen`과 `windows_screen`은 로컬 OCR와 원본 이미지를 그대로 반환한다. 외부 에이전트가 화면을 해석하기 어렵거나 조작 결과가 불명확할 때 `screen_inspect`로 작은 VLM의 관찰을 추가로 요청한다. 일반 화면 읽기나 클릭마다 API를 자동 호출하지 않는다.

```json
{"surface":"windows","question":"현재 화면을 막고 있는 팝업과 일반 탐색 버튼을 확인해 줘"}
```

지원 대상은 iPhone 미러링과 Parallels Windows 창이다. Mac 브라우저의 DOM과 일반 Mac 앱 제어는 호스트 에이전트의 도구로 처리한다. 한 장의 화면으로 Windows가 멈췄다고 확정하지 않는다. 클릭 후 변화가 없으면 새 화면과 운영체제 반응을 확인하고 같은 클릭을 반복하지 않는다.

## 설정과 비용

- 설정 → 화면 보조 → **VLM 보조 눈**에서 켜거나 끈다. 새 설치의 기본값은 꺼짐이다.
- 기존 `Chat.apiKey`의 키체인 또는 `.env` 키를 사용한다. 키는 화면이나 로그로 반환하지 않는다.
- 이미지 수신자는 `https://api.openai.com/v1/responses`로 고정한다. 텍스트 모델에 별도 게이트웨이가 설정돼 있어도 이미지를 그곳으로 보내지 않는다. OpenAI에서 사용할 수 있는 키가 필요하다.
- 기본 모델은 `gpt-5.6-luna`이며 로컬 `OPENAI_VISION_MODEL` 설정으로 바꿀 수 있다. 이미지 입력·Responses·구조화 출력과 `reasoning.effort=none`을 지원하는 모델을 사용한다.
- 원본을 보존하고 긴 변 1280픽셀 이하 JPEG 복사본을 전송한다. 출력은 최대 1000토큰, 요청은 20초 제한, 자동 재시도는 없다. 같은 프로세스에서 같은 화면·질문은 60초 동안 관찰을 재사용한다. 캐시 확인 전에도 현재 화면과 권한을 다시 확인한다.
- 반환값에 실제 입력·출력 토큰 수가 포함된다. `store:false`를 사용하며, 이 설정이 제공자의 모든 보관을 없앤다는 뜻은 아니다.

2026-09-08 공식 문서의 Luna 단가는 100만 토큰당 입력 $0.20, 출력 $1.20이다. 실제 호출 비용은 이미지와 질문·응답의 토큰 수에 따라 달라진다. [모델과 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [이미지 입력](https://developers.openai.com/api/docs/guides/images-vision), [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs).

## 관찰과 실행의 경계

결과는 `source: vlm_observation`, 모델, 화면 상태, 짧은 설명, 선택적인 좌표 후보, 토큰 사용량이다. 원본 OCR·장부·발자국·승인 상태를 수정하지 않는다. 좌표 후보와 자신감은 모델의 추정이며 성공 증거나 사람 승인이 아니다. 작은 모델은 직접 클릭하거나 도구를 실행하지 않는다. 외부 에이전트가 최신 원본 화면으로 확인하고 기존 제어 도구의 승인 경계를 지킨다.

캡처 전에는 기존 동의·Mac 권한·폰 또는 Windows 창 상태 검사를 적용한다. OCR나 질문에서 비밀번호 입력·인증서 암호·OTP·긴 식별번호·키 같은 인증 정보를 감지하면 API 전송을 거절한다. OCR 검사는 완전한 개인정보 익명화가 아니다. 외부 에이전트도 실제 인증 정보가 보이는 화면에서 호출하지 않는다. 질문·이미지·VLM 원문은 공개 플레이북이나 텔레메트리에 저장하지 않는다.

## 검증

모의 전송과 합성 화면으로 요청 형식, 개인정보 차단, 잘못된 응답·좌표·미완료·거절·네트워크 오류, 기존 게이트, 중복 비용 방지, 원본 보존을 검증한다. 실제 계정의 모델 접근 가능 여부와 실제 Windows 조작은 별도 실기로 확인한다. VLM 설치 자체를 사이트 로그인·인증·도면 수집 성공으로 기록하지 않는다.

2026-09-08 검증 결과:

- 관련 테스트 39개 통과. 실제 API 테스트는 기본 실행에서 건너뛰며 `PPOMI_VISION_LIVE_TEST=1`을 지정했을 때만 개인정보 없는 합성 화면 한 장을 전송한다.
- 기존 키로 실제 `gpt-5.6-luna` 호출 1회 성공. 입력 1810·출력 76토큰, 약 3.5초, 위 단가 기준 약 $0.0004532. 좌표 후보가 노란 사각형 내부를 가리켰지만 중심 추정은 실제 `(0.75, 0.75)`에서 `(0.75, 0.672)`로 벗어났다. 높은 confidence 값을 정확성 보장으로 사용하지 않는다. 이 한 사례는 실제 앱에서의 성능 평가를 대신하지 않는다.
- 기존 개발 서명을 유지해 `/Applications/뽀미.app`에 설치하고 이 Mac의 보조 눈 설정을 활성화했다. 설치본의 새 stdio MCP 연결에서 `screen_inspect`와 폴백 지침 노출을 확인했다. 기존 외부 에이전트 연결은 MCP 재시작 후 새 도구 목록을 읽어야 한다.
- Mac 잠금 해제 후 개인정보 없는 실제 Edge 초기 설정 화면을 최신 설치본의 `screen_inspect`로 분석하는 데 성공했다. 파란 영역이 라디오 선택이 아닌 텍스트 드래그 선택이고, 양쪽 라디오가 비어 있으며 계속 버튼이 비활성인 상태를 원본과 맞게 구분했다. 반환 상태는 `uncertain`, 좌표 후보는 `null`, 실제 사용량은 입력 2162·출력 130토큰이었다. 이 한 건의 관찰 결과로 일반적인 정확도를 보장하지 않는다.
- 별도의 제어 실기에서는 CUA로 관찰하고 Ppomi MCP로 동작하여 Windows 시작 메뉴 열기·닫기, Edge 초기 설정의 `허용 안 함` 라디오 선택, `확인 후 계속` 클릭 후 다음 페이지 진입을 확인했다. 이후 선택적 데이터 제공을 거부하여 Edge 초기 설정을 마치고 세움터 홈페이지·새 로그인 화면에 다시 진입했다. VLM이 직접 클릭한 것이 아니다.
- 세움터의 모듈 미설치 JavaScript 경고를 MCP로 확인한 뒤 공식 `KSignCASE_For_HTML5_Windows_v1.3.29.exe` 다운로드 완료와 `파일 열기` 표시를 확인했다. 사용자 승인받은 로컬 접근 허용을 적용하고 Edge 사이트 정보의 `디바이스의 앱` 토글이 켜진 것도 직접 확인했다. 접근 권한 반영은 검증되었으나 모듈 설치·인증·로그인·도면 수집 성공은 아직 아니다. 현재는 설치 파일 열기를 준비 중이다.
- 뽀미 콘솔을 다시 연 상태에서도 MCP의 Windows 시작 메뉴 클릭이 작동했다. 마우스 게임 옵션은 `게임용 자동 감지`를 유지했다. 이 결과만으로 이전 입력 실패의 원인을 확정하지 않는다.
