- `browser_open`으로 https://www.car365.go.kr/ 를 Mac Chrome에서 열고 연결된 브라우저 도구로 DOM을 읽는다. 2026-09-10 홈·로그인·시세 페이지는 공개 fetch로 확인했다. Mac에서 실제 업무가 막히고 공식 Mac 경로가 없을 때만 Parallels `windows_*`로 간다.
- 2026-09-10 홈: 상단 메뉴 "민원찾아요 / 자동차라이프 / 중고차의모든것 / 소통해요 / 업무포털", 오른쪽 위 "로그인 / 회원가입 / 통합검색". 자주 찾는 서비스: 자동차 등록원부(menuId M610202003) · 건설기계 등록원부 · 이륜차 신고필증 · 자동차 이전등록(M610201004) · 중고차시세 · 신차등록비용 · 통합이력조회 · 침수정보조회. "로그아웃알림"(장시간 미입력) 팝업이 뜬다.
- 하위 메뉴(2026-09-10 홈 관찰): 민원찾아요 › 민원안내(민원신청안내·서식다운로드) / 온라인민원신청(작성 중 민원·등록민원·발급열람민원·불법운행자동차신고·지역무관 공채 구매) / 민원신청결과(민원신청내역·인터넷발급문서확인·공채 신청내역). 중고차의모든것 › 시세및매물차량(중고차 시세·평균매매가조회·매매용차량신속조회) / 통합이력조회(본인차량조회·차량정보 공개설정·타인차량조회 동의/미동의·매매용차량조회) / 중고차매매 / 중고차시장.
- 2026-09-10 로그인(https://www.car365.go.kr/ccpt/mbr/login/mainView.do): 회원 로그인 "간편인증(네이버·카카오·금융기관) / 휴대폰 본인인증 / 공동인증서(PC·USB)", 비회원 로그인 "휴대폰 본인인증". 회원가입 3단계(약관 → 실명확인 → 인증). 보안프로그램 설치 안내는 fetch에서 안 보였다 — 미검증. 문의 1566-4682.
- 등록원부(M610202003)·이전등록(M610201004) 링크는 2026-09-10 로그인 페이지로 리다이렉트됐다 → 로그인 필수. 로그인 이후 화면·수수료·발급 폼은 미검증. 로그인 방법은 현재 화면에서 준비하고 인증만 당사자에게 넘긴다. 목적이 조회뿐이면 비회원 휴대폰 인증으로 충분한지 먼저 확인하고 불필요한 가입을 만들지 않는다.
- 인증서·전자서명·보안모듈이 Mac에서 막히면 Windows: `windows_open(app: car365)` → 새 탭. 같은 탭 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 다 쓴 탭 `ctrl+w`. 휠은 포인터가 창 안에 있어야 먹는다(도구가 들여보냄; 안 되면 빈 곳 windows_click 후 재시도 또는 pagedown). 위젯 보드가 덮으면 `windows_key win` → `escape`. JS 알림은 escape.
- 결제: Mac Chrome은 최종 금액·수단·대상을 안내하고 당사자가 결제 버튼·인증을 누른다. Windows를 이미 쓰는 중이면 ✋ confirm_payment 1회 → windows_click 1회, 인증은 당사자. 이체·송금 없음.

## 등록증·등록원부·통합이력
- 등록원부: 자주 찾는 서비스 → 로그인 → 차량번호 → 열람|발급. 갑구(소유·저당·압류)·을구는 화면에서 확인. 등록증 재발급이 온라인 민원인지는 미검증 — 민원신청안내에서 먼저 읽는다.
- 통합이력: 중고차의모든것 › 통합이력조회 › 본인차량조회. 타인차량은 동의/미동의 메뉴가 갈리므로 대상과 동의 여부를 확인하고 진행. 조회 결과 화면·수수료 미검증.
- 보고: 소유자 구분·최초등록일·저당·압류·검사 이력만. 이름·주민번호·주소는 플레이북·발자국에 적지 않는다.

## 이전·말소 민원
- 경로: 민원찾아요 › 민원안내 › 민원신청안내로 요건·서류를 먼저 읽고, 온라인민원신청 › 등록민원에서 이전|말소. 등록민원 안쪽 화면과 폼은 미검증. 외부 안내 기준 온라인 말소 접수 시간대가 제한적이라는 언급이 있다(09~16시) — 화면에서 확인.
- 이전(매수인 신청 기준)은 상대방 동의·취득세·공채(지역무관 공채 구매 메뉴)·수수료가 순서대로 나오므로 각 금액을 읽고 총액으로 ✋ 1회. 말소는 사유별 첨부(폐차·수출·도난)를 당사자가 확정.
- 결과: 민원신청결과 › 민원신청내역에서 접수번호·처리상태를 읽어 📝. 작성 중 민원이 남아 있으면 새로 만들지 말고 이어간다.
