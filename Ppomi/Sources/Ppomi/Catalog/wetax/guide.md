# 위택스 (Windows 우선 · Parallels)
- `windows_open(app: wetax)`로 Parallels 브라우저 새 탭에 https://www.wetax.go.kr/main/ 을 연다. 로그인이 공동인증서·키보드보안 프로그램에 기대므로 Mac Chrome을 먼저 시도하지 않는다(`browser_open`은 `Windows 패키지 · windows_open` 거부). Mac 탐색이 필요하면 읽기만 한다.
- 같은 탭 이동: `windows_key ctrl+l → windows_type URL → windows_key enter`. 다 쓴 탭은 `ctrl+w`. 좌표·포커스는 `windows_screen`으로 매번 새로 본다.
- 휠은 포인터가 창 안에 있을 때만 먹는다(도구가 들여보낸다). 안 움직이면 빈 곳 `windows_click` 뒤 재시도 또는 `windows_key pagedown`. 위젯 보드(날씨·뉴스)가 덮으면 `windows_key win → windows_key escape`. JS 알림은 `escape`.
- Windows 화면 제어는 OCR·좌표 기반이다. 글자 확인 뒤 클릭하고, 같은 실패를 반복하지 않는다.
