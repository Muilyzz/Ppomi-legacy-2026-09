# 선크림 습관과 사진 기록

‘몸과 생활’의 아침 선크림 카드는 사용자가 실제로 발랐다고 확인한 날짜를 모은다. 오늘 확인 버튼과 7일·28일 기록 일수, 28칸 기록판을 제공한다. 미기록은 미사용·실패로 판정하지 않으며, 기록 수를 피부 나이·차단량·SPF·노화 방지량으로 환산하지 않는다.

선크림을 세안·보습 뒤의 행동에 연결하고 사용하기 쉬운 위치에 두는 것이 이 화면의 사용 흐름이다. 제품 사용법은 [미국피부과학회 안내](https://www.aad.org/media/stats-sunscreen)를 참고한다. SPF 30 이상, UVA/UVB 차단, 내수성 제품을 권고하며 야외에서는 약 2시간마다, 수영·땀을 흘린 뒤에는 제품 안내에 따라 덧바른다. 하루 한 번의 체크는 하루 종일 충분한 보호가 유지됐다는 뜻이 아니다.

## 무엇을 눈으로 확인할 수 있는가

- **오늘의 도포:** 적합한 UV 카메라와 제품을 사용하는 경우 도포가 빠진 부위를 볼 수 있다. 일반 RGB 사진을 처리해서 실제 UV 관측으로 바꿀 수는 없다. 제품별 검출 차이가 있으므로 어둡게 보이는 정도를 실제 SPF나 UVA 차단 성능으로 환산하지 않는다. [UV 사진 연구](https://derma.jmir.org/2021/1/e24653/)
- **장기간 경과:** 월 1회 같은 카메라·조명·거리·각도·표정으로 원본 사진을 남기고 비교한다. 촬영 조건을 맞춘다는 의미이며 월 1회가 임상적으로 검증된 변화 감지 간격이라는 뜻은 아니다. 같은 얼굴도 조명에 따라 보이는 주름과 인상 나이가 달라진다. [조명 연구](https://pubmed.ncbi.nlm.nih.gov/26893277/)
- **예방 효과:** 집단 연구는 매일 사용의 효과를 뒷받침하지만, 한 사람의 ‘바르지 않았을 미래 얼굴’은 관찰할 수 없다. AI로 만든 미래 얼굴은 측정 결과로 제시하지 않는다.

사진은 현재 ‘기록 추가 → 컨디션’의 메모·첨부를 통해 비공개 원본으로 보관할 수 있다. 이번 구현에는 자동 얼굴 분석·정렬·피부 나이 점수·UV 카메라 연결이 포함되지 않는다. 얼굴 사진을 외부 AI로 전송하지 않는다.

## 개선 가능성과 근거의 범위

903명 무작위시험에서 4.5년 동안 매일 사용한 집단의 광노화 진행이 덜했다. 논문의 24%는 피부 미세표면 등급 진행의 상대오즈 0.76이며 개인의 얼굴이 24% 덜 늙는다는 예측에 사용할 수 없다. [Hughes 등, 2013](https://pubmed.ncbi.nlm.nih.gov/23732711/)

32명이 SPF 30 제형을 52주 사용한 전후 연구에서는 피부결·색소 등 평가 개선을 보고했다. 작은 연구이고 대조군이 없어 보습 제형이나 다른 변화와 분리해 선크림만의 개선 효과를 확정할 수 없다. 따라서 ‘개선은 절대 없다’거나 ‘회춘을 보장한다’는 설명 모두 피한다. [Randhawa 등, 2016](https://pubmed.ncbi.nlm.nih.gov/27749441/)

## 데이터

공통 기록의 `habit` 종류, `activityID: sunscreen`, `activityStatus: completed/retracted`를 사용한다. 실제 바른 날짜와 시간대는 `activityDay`·`activityTimeZone`에, 보고·확인 시각은 `occurredAt`에 분리해 저장한다. 어제 바른 일을 오늘 말해도 어제 기록으로 집계하며, 미래 완료는 저장하지 않는다. 실제 도포 시각이 불명확하므로 버튼의 시각은 사용자의 확인 시각이다. 출처와 수정 이력을 남기며 ‘잘못 눌렀어요’는 삭제 대신 완료 표시를 취소한다. 음성·MCP의 사용자 보고도 같은 형식으로 저장한다. 사진이나 알림 발송·무응답에서 완료를 추론하지 않는다.
