# 교통민원24(이파인) (Windows 우선 · 경찰청)
- 처음부터 `windows_open(app: efine)`으로 Parallels Windows 브라우저에서 연다. 로그인 화면이 웹보안·키보드보안(TouchEn·nxbiz) 설치를 요구하고 공동인증서·금융인증서 로그인을 쓰므로 Mac Chrome은 탐색용(`browser_open(url)`)으로만 쓴다. 폰으로 보내지 않는다.
- 같은 탭 이동: `windows_key ctrl+l → windows_type URL → windows_key enter`. 다 쓴 탭은 `windows_key ctrl+w`. 좌표·포커스는 매번 `windows_screen`으로 새로 확인한다.
- 휠은 포인터가 창 안에 들어온 뒤에만 먹는다(도구가 들여보낸다). 안 움직이면 페이지 빈 곳을 `windows_click` 한 뒤 다시, 또는 `windows_key pagedown`. 위젯 보드(날씨·뉴스)가 덮으면 `windows_key win` → `windows_key escape`. 자바스크립트 알림은 escape.

## 절차
- 미납 과태료·범칙금: 홈 → 조회 → 과태료 → 미납과태료(범칙금은 미납범칙금). 로그인 화면이 뜨면 당사자가 고른 인증 탭을 클릭해 준비하고 성명·주민번호·인증서 암호·앱 승인은 👤. 로그인 뒤 새 화면에서 목록을 `windows_screen`으로 읽고 위반일·금액·납부기한을 보고한다. 납부는 사용자가 요청했을 때만: 대상 선택 → 납부 버튼까지 진행 → ✋ confirm_payment(최종 금액·수단·대상 한 줄) → `windows_click` 1회 → 카드 인증은 👤 → 📝 결과 보고 · record_spend.
- 무인단속 내역: 조회 → 과태료 → 최근단속내역. 로그인 준비 → 👤. 목록을 끝까지 스크롤해 단속일시·위반 종류·장소·확정 상태를 보고한다. 확정 전 내역은 과태료 금액이 없을 수 있다고 적는다.
- 운전면허 벌점: 조회 → 운전면허 → 운전면허 벌점. 로그인 준비 → 👤. 누산 벌점과 화면의 정지 기준 안내를 그대로 보고한다.
- 보안 프로그램 설치 요구가 뜨면 재설치를 반복하지 말고 OS·설치 상태를 먼저 확인한다. 설치 실행·브라우저 새 접근 권한은 현재 대상과 효과를 설명하고 👤.
- 가족 계정: 이번 당사자의 인증만 쓴다. 이전 세션·인증을 물려받지 않고, 작업이 끝나면 `windows_key ctrl+w`로 탭을 닫는다.
- 보고·발자국에 이름·주민번호·차량번호·실제 금액 외 개인정보를 적지 않는다. 실패 시 화면과 원인을 먼저 확인하고 같은 실패를 반복하지 않는다.
- 검증 상태: 공개 홈·메뉴·로그인 페이지 텍스트만 확인. Windows 실기·로그인·조회·납부 전체 경로는 미검증.
