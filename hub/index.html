홈 화면에서 바로 열어요

지금 이 웹 앱 홈을 Safari에서 열고, 아래 순서대로 한 번만 추가해 주세요. 다음부터 뽀미 아이콘으로 시작할 수 있어요.

iPad의 Safari에서 사용하는 방법입니다. iPadOS 버전에 따라 메뉴 모양과 위치가 조금 다를 수 있어요.

  1. 웹 앱 주소
    01

    공유 버튼 누르기

    Safari 도구 막대에서 네모 위로 화살표가 올라가는 버튼을 눌러 주세요.

  2. ··· 더 보기＋ 홈 화면에 추가
    02

    홈 화면에 추가 선택

    공유 메뉴에서 ‘홈 화면에 추가’를 찾으세요. 보이지 않으면 ‘더 보기’를 누르거나 목록을 내려 보세요.

  3. 웹 앱으로 열기 추가
    03

    추가하면 끝

    ‘웹 앱으로 열기’가 보이면 켜고 ‘추가’를 누르세요. 다음부터 홈 화면 아이콘으로 열 수 있어요.

위 그림은 버튼을 찾기 위한 예시예요. 실제 추가는 Safari 메뉴에서 직접 진행해 주세요.
