# v0.2 Mac 셸 — 메인 앱에서 테스트 (example 아님)

소비자가 클릭하는 Mac 앱은 **이미 있는 `뽀미.app` / `Ppomi.app`** 이다. 새 `ppomi-*` 패키지를 만들지 않는다.

**패키지 example CLI로 스모크하지 않는다.** Home → KB 는 앱 작업대(또는 앱이 내놓는 `path_cold_start` MCP)에서 돌린다.

## Mac에서 열고 한 스텝

Finder에서 `scripts/open-mac-shell.command` 를 더블클릭한다. 터미널이 뜨고, 있는 앱을 연다. 없으면 `scripts/make-app.sh` 로 `dist/Ppomi.app` 을 만든 뒤 연다.

```sh
scripts/open-mac-shell.sh
scripts/open-mac-shell.sh --build          # 항상 다시 패키징
scripts/open-mac-shell.sh --dry-run        # 빌드/열기 없이 안내만
scripts/open-mac-shell.sh --self-check     # Linux에서도 통과하는 문자 검사
```

또는

```sh
cd Ppomi && swift run Ppomi
# 설치 번들
LOCAL_SIGN_ID="Apple Development: …" scripts/make-app.sh
open dist/Ppomi.app
```

권한: 시스템 설정 › 손쉬운 사용 · 화면 기록 을 **뽀미**에 켠다. 폰은 **잠근 채** Mac 옆에 두고 iPhone 미러링을 연결한다.

서명: 이 스크립트는 `SIGN_ID` / `NOTARY_PROFILE` 을 거부한다. TCC가 안 끊기게 쓰려면 `LOCAL_SIGN_ID="Apple Development: …"` 만. 스토어·공증은 하지 않는다.

이미 `/Applications/뽀미.app` 이 있으면 그걸 연다 (`--build` 가 아닐 때).

### 앱에서 Home → KB

1. 뽀미를 연다. 대화 창 제목줄 또는 작업대 제어 머리띠에 **Home → KB** 가 보인다.
2. (선택) 나(아바타) → Google 로그인. Clerk 웹 로그인(who)과 별개다. 이 Mac 세션이 where 다.
3. 작업대가 열리거나 로그인이 끝나면 `DeviceRegistry.attach` 가 이 macos 기기를 로컬 플릿에 올린다. 머리띠에 `이 Mac · macos · 온라인`.
4. **Home → KB** 를 누른다. 라이브 미러링에 `phone_key home` 후 `phone_open(kb-enterprise)` (KB스타기업뱅킹). Face ID·로그인에서 멈춘다.
5. 계좌번호·비밀번호는 읽거나 반환하지 않는다.

같은 한 스텝을 MCP로:

```sh
# 앱과 같은 손. packages/.../example 이 아니다.
# 클라이언트에 Ppomi --mcp 를 붙인 뒤 path_cold_start(app: "kb-enterprise")
```

절차 탭에서 KB스타기업뱅킹을 고르면 **Home → KB (로그인 전 멈춤)** 도 같은 도구를 부른다.

### 화면 기록 보존 (은행 화면 주의)

`path_cold_start` 가 KB스타기업뱅킹을 연 뒤 `phone_open` 의 확인 캡처는 일반 화면 경로(`Phone.screen`)를 거치므로 `data/shots/` 에 PNG(7일 보관)와 OCR 결과 `.jsonl`(영구 보관)로 남는다. 앱이 이미 로그인된 상태였다면 이 확인 프레임에 계좌 화면이 포함될 수 있다. `path_cold_start` 는 계좌·비밀번호를 **반환**하지 않지만, 이 로컬 캡처는 남는다. 은행 화면은 보존하지 않도록 콜드스타트 확인을 비공개 캡처(`Phone.privateScreen`)로 바꾸거나 이 경로의 shots 를 즉시 삭제하는 것은 **후속 작업**이며 이 PR에서 구현하지 않는다.

## web / Clerk (`ppomi-web`)

`hub/` 는 공개 카탈로그다. 본인증(who)은 `web/` 만. Mac 앱 세션은 여전히 `ppomi://auth` Google(Supabase).

```sh
cd web
cp -n .env.example .env.local   # 실제 pk_/sk_ 를 사람이 붙인다
npm install && npm run dev      # http://127.0.0.1:3000
```

키 있으면 Google 로그인 → `/account`. 키 없으면 설정 안내만. 설계는 [clerk-migration.md](clerk-migration.md).

## 더 나중 (이 문서 밖)

- Mac 앱 Clerk (지금 `ppomi://auth` = Supabase)
- `hub/` 와 `web/` 로그인 면 합치기
- 앱 안에 `web/` WKWebView
- 스토어 서명·공증
- Face ID 자동화 · Windows 인스톨러 · E2E vault
- 콜드스타트 확인 프레임을 은행 화면 보존 없이 처리 (비공개 캡처 또는 즉시 삭제)
