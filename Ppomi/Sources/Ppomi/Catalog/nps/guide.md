# 국민연금 전자민원 (Windows 우선 · Parallels)
- `launch.target: windows`. 로그인 화면이 키보드 보안·백신 프로그램 설치를 권장하고 공동인증서·금융인증서 탭을 제공하므로 처음부터 `windows_open(app: nps)`으로 Parallels 기본 브라우저에서 연다. Mac Chrome(`browser_open`)은 공개 메뉴 확인 같은 탐색에만 쓰고, 로그인·조회·발급은 Windows에서 한다.
- Windows 이동: `windows_open`은 새 탭. 같은 탭 이동은 `windows_key ctrl+l → windows_type URL → windows_key enter`, 다 쓴 탭은 `windows_key ctrl+w`. 휠은 포인터가 창 안에 들어온 뒤에만 먹는다(도구가 들여보낸다). 안 움직이면 빈 곳을 `windows_click` 한 뒤 다시, 또는 `windows_key pagedown`. 위젯 보드(날씨·뉴스)가 덮으면 `windows_key win` 뒤 `windows_key escape`. 자바스크립트 알림은 escape. 좌표·포커스는 매번 `windows_screen`으로 새로 확인한다.

## 관찰 (2026-09-10, WebFetch 공개 화면)
- https://www.nps.or.kr/ 는 게이트 페이지. 카드 "대표홈페이지 / 개인민원 / 기금운용본부 / 사업장민원(국민연금EDI) / 중앙노후준비지원센터". 개인민원 카드 → https://www.nps.or.kr/elctcvlcpt/comm/getOHAC0000M3.do?menuId=MN24001727. 옛 주소 minwon.nps.or.kr 은 여기로 302.
- 개인민원 홈 상단 메뉴 "전자민원 / 국민참여 / 정보공개 / 연금소식 / 연금정보 / 공단소개". 로그인 https://www.nps.or.kr/lgn/loginForm.do. 자주 찾는 서비스에 "예상연금액 조회", "가입내역조회"(/elctcvlcpt/inquiry/getOHAC0001M0.do), "가입자 가입증명(국/영문)"(/elctcvlcpt/cfdcissu/getOHAC0020M0.do).
- 로그인 페이지 탭 "모바일 신분증 / 간편인증 / 공동인증서 / 금융인증서 / 브라우저인증서". "키보드 보안 프로그램 설치를 권장" 문구. 탭 선택·안내 읽기까지 에이전트, 실제 인증은 당사자.
- 조회 하위 메뉴(비로그인 화면에서 관찰) "가입내역 / 예상연금 / 부과·납부내역 / 납부내역". 개인 상위 메뉴 "전체 / 조회 / 증명서 발급 / 신고·신청 / 가입지원·신고센터 / 인터넷 납부서비스".
- 비로그인으로 열면 "로그인을 해주세요" 또는 "로그인이 필요한 서비스 입니다 / 돌아가기", 세션 만료 문구("시간이 만료되었거나, 다른 기기에서 로그인되어…")가 뜬다. 만료면 다시 준비하고 사람에게 인증만 넘긴다.
- 미검증: 로그인 뒤 실제 조회 표 구성, 예상연금 화면의 정확한 URL(자주 찾는 서비스의 "예상연금액 조회"는 외부 csa 포털로 연결됐고 csa.nps.or.kr 은 제목 "내연금"만 읽힘), 증명서 발급 옵션 항목·출력 프로그램 종류·PDF 저장 경로, 수수료 표시 여부, Parallels ARM 에서 보안 프로그램 동작.

## 예상연금 조회
1. `windows_open(app: nps)` → ⊙개인민원 → 상단 "전자민원" → 개인 → 조회 → 예상연금. 안 보이면 자주 찾는 서비스 "예상연금액 조회"(외부 포털 가능성, 새 탭 확인).
2. 로그인 화면이면 사용자가 정한 방식 탭을 고르고 👤인증. 간편인증은 폰 앱 승인이므로 필요한 행동 한 줄만 안내한다.
3. 로그인 뒤 같은 메뉴로 재진입(자동 복귀 안 될 수 있음). ↓표를 끝까지 읽고 📝현재가치·미래가치·수령 개시 나이만 보고. 다른 가족의 세션을 재사용하지 않는다.

## 가입내역·납부 조회
1. `windows_open(url)`로 가입내역조회 URL 직접 열기 → "로그인을 해주세요" → 👤인증.
2. 조회 → 가입내역: 사업장·지역 구분, 총 가입기간. 조회 → 부과·납부내역|납부내역: 납부 개월, 미납 개월, 최근 납부월.
3. 📝요약만 보고. 납부·자동이체 신청·선납 버튼은 누르지 않는다. 화면에 뜬 사업장명은 발자국에 적지 않는다.

## 가입증명서 발급
1. `windows_open(url)`로 가입자 가입증명 URL 열기 → "로그인이 필요한 서비스" → 👤인증.
2. 증명서 발급 → 가입자 가입증명(국/영문). 옵션(용도·언어·주민번호 뒷자리 표시)은 사용자가 정한 값만, 미정이면 국문·가림 기본. 주민번호 전체 표시는 자동 선택하지 않는다.
3. 출력 프로그램 설치 안내가 뜨면 공식 안내만 이어가고 관리자 인증·새 권한은 👤. 수수료가 표시되면 ✋ confirm_payment 1회 → windows_click 1회.
4. 📝발급 완료 문구·저장 위치·문서 유효 안내. 문서 내용(이름·주민번호)은 보고에 옮기지 않는다.

## 발자국·기록
- note_footprint 에는 메뉴 이름·화면 상태·막힌 원인만. 이름·주민번호·인증 방식의 실제 값·세션 URL·금액 원문은 남기지 않는다.
- 검증 상태: 공개 화면의 메뉴·URL·로그인 탭만 2026-09-10 WebFetch 로 확인. Windows 실기(설치·로그인·조회·발급)는 전부 미검증.
