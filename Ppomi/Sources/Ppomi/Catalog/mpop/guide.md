# 삼성증권 mPOP
- 2026-09-11 화면 라벨·경로는 미검증 — 첫 실행에서 단계마다 verify_step 으로 실제 라벨을 남긴다.
- 주문은 준비까지만. 종목·매수/매도·수량·가격을 입력한 뒤 phone_screen 으로 주문 요약(종목, 구분, 수량, 단가 또는 시장가, 예상 주문금액, 주문가능금액·매도가능수량)을 읽어 사용자에게 한 줄로 안내한다. 매수·매도 버튼과 주문 확인 팝업의 확인은 당사자가 미러링 창이나 폰에서 직접 누른다. confirm_payment 로 대신 승인받아 탭하지 않는다 — 매수·매도는 결제 경계 단어가 아니라 코드가 막지 않으므로 이 규칙으로 지킨다.
- 가격: 사용자가 '시장가'라고 하면 시장가 탭, 금액을 말하면 지정가로 그 금액. 호가 단위에 안 맞으면 앱이 거절하니 오류 문구를 읽어 보고한다. 장 마감 뒤(15:30 이후)는 예약주문·시간외로 갈리므로 화면 안내를 읽어 사용자에게 확인하고, 자동으로 시간외 주문으로 바꾸지 않는다.
- 주문가능금액이 예상 주문금액보다 적거나 매도가능수량이 모자라면 주문 준비를 멈추고 보고한다. "신용", "미수", "대출", "이체", "출금" 이 든 버튼은 누르지 않는다.
- OCR 은 ▲▼ 등락 기호를 숫자(7 등)로 읽을 수 있다. 현재가·등락률은 기호 앞뒤를 의심하고, 입력한 수량·가격은 주문 칸을 phone_screen 으로 다시 읽어 확인한 뒤 요약한다.
- 공지·이벤트·투자 위험 안내 팝업은 ⎋ 로 닫는다. 로그인은 간편비밀번호·생체인증이라 사용자 몫 — 한 줄로 부탁하고 phone_wait 로 기다린다.
- 사용자가 눌렀다고 하면 주문 접수 결과 화면(또는 체결/미체결 조회)에서 주문번호·체결 여부·체결가를 읽어 보고한다. 금액·주문번호·계좌는 검증 장부와 발자국에 적지 않는다.
- 끝엔 phone_key home — 증권 앱을 미러링에 띄워 두지 않는다.
