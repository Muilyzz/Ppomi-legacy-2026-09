# 홈택스 (Mac Chrome 우선 · 막힌 단계만 Windows)

## 열기
- `browser_open`으로 https://hometax.go.kr/ 를 Mac Chrome에서 열고 연결된 브라우저 도구로 DOM을 읽는다. PC 웹이라는 이유만으로 Windows를 선택하지 않는다.
- 2026-09-10 WebFetch: https://hometax.go.kr/ 제목 "국세청 홈택스". 본문은 JS 렌더(WebSquare) 셸이라 상단 메뉴·로그인 링크는 정적 응답에서 보이지 않았다 → 메뉴 라벨은 미검증, 실제 화면에서 읽는다.
- 2026-09-10 https://www.hometax.go.kr/ui/pp/yrs_index.html (신고안내 임시페이지)에서 관찰: 링크 "연말정산 간소화 (공제자료 조회/발급) 바로가기", "편리한 연말정산 (공제신고서 작성 등) 바로가기", "홈택스 바로가기", "부가가치세 신고 서비스 바로가기". 링크 대상은 JS이며 이용 집중기 안내 문구가 있었다.
- 팝업·공지가 글자를 가리면 X·닫기로 닫는다.

## 로그인 (준비는 에이전트 · 인증은 당사자)
- 로그인 페이지 URL: 미검증. 2026-09-10 …/ui/pp/login/UTXPPABA01.xml 은 제목만 있는 JS 셸이었다. 홈 오른쪽 위 로그인 진입점을 현재 화면에서 찾는다.
- 로그인 방식(간편인증·공동인증서·아이디 등)의 배치는 미검증. 현재 화면에서 방식을 고르고 준비한 뒤 자격 증명·인증서 암호·OTP·CAPTCHA·인증용 주민번호·새 동의만 당사자에게 한 줄로 넘긴다.
- 세션 만료 시 기존 승인 범위에서 다시 준비한다. 다른 가족의 세션·인증을 재사용하지 않는다.

## 작업 (메뉴 경로 전부 미검증 · 2026-09-10 공개 페이지에서 관찰 못 함)
- 연말정산 간소화: 장려금·연말정산 계열 메뉴 → 연말정산 간소화 → 소득·세액공제 자료 조회. 검색 결과 제목 "국세청 홈택스 연말정산 간소화 서비스"(w2xPath=/ui/pp/index_pp.xml&tmIdx=10&tm2lIdx=1003000000&tm3lIdx=1003050000)는 관찰이 아니라 검색 인덱스 제목. 귀속 연도·항목을 고른 뒤 화면 금액만 보고한다.
- 현금영수증 사용내역: 계산서·영수증·카드 계열 메뉴 → 현금영수증 → 근로자·소비자 조회. 검색 결과 제목 "계산서ㆍ영수증ㆍ카드 > 근로자·소비자 조회"(tmIdx=46&tm2lIdx=4604010000&tm3lIdx=4604010100) 역시 검색 인덱스 제목. 기간을 정해 조회하고 목록 끝까지 스크롤한 뒤 합계를 보고한다.
- 근로·자녀장려금: 장려금 계열 메뉴 → 근로·자녀장려금 → 신청안내 대상 조회 / 심사진행상황 조회. 조회만 한다. 신청·수정·취소 제출은 화면의 대상·효과를 보여 주고 당사자가 확정한다.
- 조회 결과의 이름·주민번호·계좌·사업자번호는 플레이북·발자국에 적지 않는다. 금액·기간·상태만 보고한다.

## Windows (Parallels) — Mac에서 막혔을 때만
- 홈택스는 보안 프로그램 설치를 요구하거나 공동인증서 로그인이 필요할 수 있다. Mac에서 해당 단계가 막히고 공식 Mac 경로로 해결되지 않을 때 `windows_open(app: hometax)`로 Parallels에서 먼저 연다.
- 같은 탭 이동: `windows_key ctrl+l → windows_type URL → windows_key enter`. 다 쓴 탭은 `windows_key ctrl+w`.
- 휠은 포인터가 창 안에 있을 때만 먹는다(도구가 들여보낸다). 안 움직이면 빈 곳을 windows_click 한 뒤 다시, 또는 windows_key pagedown.
- 위젯 보드(날씨·뉴스)가 덮으면 windows_key win 뒤 windows_key escape. JS 알림은 escape.
- 보안 프로그램 설치 안내는 이미 허용된 준비로 진행하되, 관리자 인증·새 권한은 당사자에게 넘긴다. 좌표·포커스는 매번 windows_screen으로 새로 확인한다.

## 결제 경계
- 조회 작업에는 결제가 없다. 결제가 생기면 Mac Chrome은 최종 금액·수단·대상을 안내하고 당사자가 직접 누른다(외부 브라우저 클릭에는 승인 코드 경계가 없다). Windows는 ✋ confirm_payment 승인 1회 → windows_click 1회, 결제 인증은 당사자.
