# 정부24 (Windows 우선)
- 보안 프로그램 설치·공동인증서 로그인이 있는 사이트라 `windows_open(app: gov24)`으로 Parallels Windows 브라우저에서 연다. Mac Chrome은 공개 페이지 탐색만.
- 같은 탭 이동: `windows_key ctrl+l → windows_type URL → windows_key enter`. 다 쓴 탭 `ctrl+w`. 휠은 포인터가 창 안에 들어온 뒤에만 먹는다. 위젯 보드가 덮으면 `windows_key win → escape`. JS 알림은 `escape`.
- 2026-09-10 WebFetch: https://www.gov.kr/ 는 https://plus.gov.kr/ 로 302 리다이렉트. 사이트명 "정부24". 상단 메뉴 "민원서비스 / 혜택알리미 / 생활 / 정책정보 / 고객센터". 홈 "자주 찾는 서비스"에 "토지(임야)대장 / 주민등록등본(초본) / 자동차등록원부 / 건축물대장 / 가족관계증명서". 홈 알림 "국민비서 서비스는 인증서 등록이 필요합니다 → 간편인증 등록".
- 2026-09-10 로그인 https://plus.gov.kr/login : 개인 "모바일 신분증 / 간편인증 / 공동인증서 / 금융인증서 / 아이디 로그인 / QR코드 로그인 / 비회원 로그인(개인)", 법인 "공동인증서 / 금융인증서 / 아이디 로그인 / 비회원 로그인(법인)". 회원가입 `/member/signUpAgree`, 인증센터 `/member/authCenter`. 실기 로그인은 미검증.
- 로그인: 당사자가 쓰는 방식을 세션에서 알면 그 탭까지 열어 둔다. 간편인증(앱 승인)·인증서 암호·모바일 신분증·비회원 로그인의 주민번호는 당사자. 비회원으로 되는 민원은 가입을 만들지 않는다.
- 팝업: 공지·앱 설치 유도가 뜨면 X·닫기. 새 동의(마케팅·권한)는 자동 체크 안 함.

## 주민등록등본 발급
- 2026-09-10 안내 페이지 https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000015 "주민등록표 등본(초본) 발급": 버튼 "신청하기 / 발급하기", 수수료 1,000원/통(29조의2 대체 증명 1,500원), 인터넷 발급은 로그인 필요, 본인 또는 대리인. `…ViewApp.do` 주소는 로그인으로 302.
- 경로: 홈 통합검색 ⌨"주민등록등본" → ⊙"주민등록표 등본(초본) 발급" → ⊙발급하기. 로그인 후 등본|초본, 수령 방법(본인출력 / 전자문서지갑 / 제3자 제출 — 검색 결과 기준, 화면 미검증), 통수. 신청 화면의 실제 항목명은 미검증이므로 windows_screen으로 읽고 고른다.
- 수수료가 화면에 있으면 ✋ confirm_payment(금액·수단·통수 한 줄) → windows_click 1회 → 결제 인증은 당사자. 본인출력 등 무료 표시면 승인 없이 진행.
- 📝 처리 상태와 문서 출력·저장 여부만 보고. 세대원 이름·주민번호는 적지 않는다.

## 보조금24 수혜 조회
- 2026-09-10: 보조금24 주소 https://www.gov.kr/portal/rcvfvrSvc/main 은 https://plus.gov.kr/portal/benefitV2 (혜택알리미)로 302. 하위 메뉴 "나의 혜택 / 관심 / 발견 / 간편찾기 / 전체 혜택 / 설정". 나의 혜택 `/portal/benefitV2/myBenefit` 은 로그인 필요, 설정에 가족등록.
- 경로: 상단 ⊙혜택알리미 → ⊙나의 혜택 → 👤로그인 → ↓목록 끝까지 windows_screen으로 읽기.

- 가족 조회는 그 가족의 계정으로. 설정 → 가족등록은 새 동의이므로 당사자.
